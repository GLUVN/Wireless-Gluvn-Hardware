The hardware

Ten analog sensors. One compact wearable platform.

Each glove combines five flex sensors, five force-sensitive resistors and the IMU inside an M5StickC Plus 1.1. The custom PCB was designed to keep the system compact while providing a practical sensor interface.

5 Flex sensors
5 FSR pressure sensors
1 CD4067 multiplexer
BLE Wireless data link
Architecture

Why the custom PCB?

The ESP32 does not provide enough convenient ADC inputs for ten analog sensors, so GLUVN uses a CD4067 analog multiplexer to bring the sensor set into a single ADC channel.

Signal path

5 × Flex sensors + 5 × FSR pressure sensors │ ▼ Analog signal conditioning │ ▼ CD4067 multiplexer │ ▼ Single ADC input │ ▼ M5StickC Plus 1.1 ESP32 + IMU + BLE │ ▼ GLUVN software │ ▼ MIDI

Separate filtering

Flex and pressure sensors use different RC conditioning so the analog front-end matches their different response requirements.

Compact design

The custom board keeps the sensor interface close to the M5Stick while reducing wiring and GPIO requirements.

Designed for interaction

The hardware is intended for real-time musical interaction rather than simply collecting sensor data.

Mechanical design

The electronics live inside a custom enclosure.

The PCB and M5Stick assembly were designed alongside the enclosure so the electronics could remain compact enough for wearable use.

The result

Hardware you can actually put on your hands.
